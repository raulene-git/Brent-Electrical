# Brent Electrical: website

Website for **Brent Electrical**, a local electrician business. Live at **[brentelectrical.co.uk](https://brentelectrical.co.uk)**.

## What's here

- **Landing page** (`index.html`): branded "coming soon" page while the full site is built
- **Cotswold Homes project page** (`cotswolds/`): a gallery of a completed lighting installation (pendants, island lighting, downlights)
- Responsive layout in plain **HTML, CSS and JavaScript**, with no build step

## Hosting

Served by **GitHub Pages** with a custom domain (`CNAME`). Pushing to `main` deploys.

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
python -m http.server 8000
```

## Structure

```
index.html      Landing page
styles.css      Shared styles
script.js       Small UI behaviour
cotswolds/      Project showcase page
assets/         Logos and project photos
```
